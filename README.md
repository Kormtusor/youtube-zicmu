# 🎵 YouTube Zicmu

**YouTube Zicmu** est une application de bureau développée avec [Electron](https://www.electronjs.org/) et [Vite](https://vitejs.dev/) qui permet d'accéder à [YouTube Music](https://music.youtube.com/) dans une interface personnalisée, sans passer par un navigateur web.
L'application à été réalisée dans le but de pouvoir utiliser l'application comme une application à part dans [OBS](https://obsproject.com/fr/) afin d'avoir une source audio à part au lieu du navigateur complet.
